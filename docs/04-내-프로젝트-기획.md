# STEP 04: 내 프로젝트 기획

## 학습 목표

지금까지 익힌 Copilot 사용 흐름을 바탕으로 직접 만들고 싶은 프로젝트를 정리합니다.

## 이제 내 프로젝트를 만들어 봅시다

앞에서는 준비된 프로젝트를 이용해 체크리스트 웹앱을 만들었습니다. 이제 평소 업무나 일상에서 불편했던 일을 하나 골라 나만의 프로젝트로 발전시켜 봅니다.

처음부터 모든 기능을 만들 필요는 없습니다. 사용자가 가장 필요로 하는 기능 하나가 작동하는 작은 버전부터 시작하면 됩니다. 이렇게 핵심 가치만 확인할 수 있게 만든 첫 번째 버전을 MVP라고 합니다.

## 프로젝트 아이디어 정리하기

[내 프로젝트 기획서](../worksheets/내-프로젝트-기획서.md)에 다음 내용을 작성합니다.

1. **프로젝트**: 무엇을 만들고 싶나요?
2. **사용자**: 누가 사용하나요?
3. **문제**: 사용자는 어떤 상황에서 무엇이 불편한가요?
4. **핵심 기능**: 사용자가 어떤 행동을 하면 어떤 결과가 나오나요?
5. **제외 범위**: 첫 번째 버전에서 만들지 않을 기능은 무엇인가요?
6. **완료 기준**: 어떤 결과를 확인하면 완성인가요?

핵심 기능은 다음 형식의 한 문장으로 작성합니다.

```text
사용자가 [행동]하면 [결과]를 확인할 수 있다.
```

예를 들어 점심 메뉴 추천 프로젝트라면 다음과 같이 정리할 수 있습니다.

```text
사용자가 원하는 식사 조건을 고르면 조건에 맞는 점심 메뉴 하나를 확인할 수 있다.
```

회원가입, 지도, 리뷰처럼 핵심 기능이 작동하는 데 꼭 필요하지 않은 기능은 첫 번째 버전에서 제외합니다.

## 기획 완료 기준

- [ ] 만들고 싶은 프로젝트를 한 문장으로 설명할 수 있습니다.
- [ ] 사용자와 해결할 문제가 분명합니다.
- [ ] 가장 먼저 만들 핵심 기능이 하나로 정해져 있습니다.
- [ ] 사용자의 행동과 화면에 나타날 결과가 연결되어 있습니다.
- [ ] 첫 번째 버전에서 제외할 기능을 정했습니다.
- [ ] 완성 여부를 직접 확인할 수 있습니다.
