# STEP 01: GitHub Copilot 이해

## 학습 목표

GitHub Copilot이 무엇인지, 무엇을 도와줄 수 있는지 알아봅니다.

## GitHub Copilot이란?

GitHub Copilot은 **프로그램 만들기를 도와주는 AI 도우미**입니다.

동료에게 “버튼을 누르면 오늘의 메뉴를 추천해 주는 웹페이지를 만들고 싶다”고 설명하듯이, Copilot에게 만들고 싶은 것을 자연어로 전달할 수 있습니다. 그러면 Copilot이 필요한 파일과 작업 순서를 알려 주거나 직접 파일을 만들어 줍니다.

> [!TIP]
> GitHub Copilot = 내가 설명한 내용을 바탕으로 계획과 코드 작성을 도와주는 AI 작업 파트너

## Copilot이 지원하는 작업

- 만들고 싶은 내용을 함께 정리할 수 있습니다.
- 어떤 순서로 만들지 계획을 세울 수 있습니다.
- 웹페이지에 필요한 파일을 만들 수 있습니다.
- 어려운 코드와 오류를 쉬운 말로 설명할 수 있습니다.
- 원하는 부분을 찾아 수정할 수 있습니다.
- 프로젝트 사용 방법을 문서로 정리할 수 있습니다.

## Copilot의 한계

아닙니다. Copilot은 가끔 틀린 답을 하거나 작동하지 않는 코드를 만들 수 있습니다.

예를 들어 실제로 없는 기능을 있다고 말하거나, 요청하지 않은 파일을 바꾸거나, 버튼을 눌러도 작동하지 않는 코드를 만들 수 있습니다. 그래서 결과는 반드시 사람이 직접 확인해야 합니다.

> [!IMPORTANT]
> 무엇을 만들지는 사람이 정합니다. Copilot은 방법을 제안합니다. 마지막 확인과 결정도 사람이 합니다.

## 오늘 사용하는 도구

| 도구 | 쉬운 비유 | 하는 일 |
|---|---|---|
| Visual Studio Code | 작업 책상 | 프로젝트 파일을 열고 수정합니다. |
| GitHub Copilot | 옆자리 AI 도우미 | 설명을 듣고 계획과 작업을 도와줍니다. |
| 웹 브라우저 | 결과 확인 창 | 만든 웹페이지가 실제로 동작하는지 봅니다. |
| Git | 저장 지점 | 파일이 바뀐 내용을 기록합니다. |
| GitHub | 온라인 보관함 | 프로젝트를 인터넷에 저장하고 공유합니다. |

오늘은 다음 순서로 사용합니다.

```text
Visual Studio Code에서 파일 만들기
→ Copilot에게 도움받기
→ 브라우저에서 직접 확인하기
→ Git으로 기록하기
→ GitHub에 저장하기
```

## Copilot 채팅의 사용 방법

| 방법 | 언제 사용하나요? |
|---|---|
| Ask | 모르는 것을 질문하거나 설명을 들을 때 |
| Plan | 무엇을 어떤 순서로 만들지 먼저 정할 때 |
| Agent | 실제 파일을 만들고 수정할 때 |

화면에 따라 이름이나 위치가 조금 다르게 보일 수 있습니다.

> [!TIP]
> 처음에는 Ask로 물어보고, Plan으로 순서를 정한 뒤, Agent로 실제 작업을 시작하세요.

## Copilot과 처음 대화하기

### 1단계: Copilot 채팅 열기

Visual Studio Code에서 Copilot 아이콘을 누릅니다.

### 2단계: Ask 선택하기

채팅창의 모드 선택 메뉴에서 **Ask**를 선택합니다.

### 3단계: 아래 문장 보내기

```text
나는 개발 경험이 없고 오늘 처음 GitHub Copilot을 사용합니다.
Copilot이 도와줄 수 있는 일과 내가 직접 확인해야 하는 일을
각각 세 가지씩 쉬운 말로 설명해 주세요.
파일은 만들거나 수정하지 마세요.
```

### 4단계: 답변 살펴보기

답변에서 Copilot이 할 일과 사람이 할 일이 나뉘어 있는지 확인합니다. 어려운 단어가 있다면 아래처럼 다시 물어봅니다.

```text
어려운 전문용어 없이 일상적인 예를 들어 다시 설명해 주세요.
```

## 안전한 사용 원칙

- 비밀번호와 외부 서비스 연결에 사용하는 비밀 코드(API 키)를 입력하지 않습니다.
- 주민등록번호, 고객정보, 회사 내부자료를 입력하지 않습니다.
- 파일 삭제나 프로그램 설치를 제안하면 이유를 먼저 확인합니다.
- 만든 결과는 브라우저에서 직접 실행해 봅니다.
- 이해하지 못한 결과를 그대로 제출하지 않습니다.

## 문제 해결 가이드

- Ask 메뉴가 없다면 강사 화면과 비교해 비슷한 이름의 메뉴를 찾습니다.
- 설명이 어렵다면 `비개발자가 이해할 수 있는 표현으로 다시 설명해 주세요`라고 요청합니다.
- Copilot 답변과 실제 화면이 다르면 실제 파일과 화면을 기준으로 판단합니다.
- 결제, 로그인, 개인정보가 관련되면 작업을 멈추고 멘토에게 물어봅니다.

## 학습 완료 확인

- [ ] GitHub Copilot이 무엇인지 한 문장으로 설명할 수 있습니다.
- [ ] Visual Studio Code와 Copilot의 차이를 알고 있습니다.
- [ ] Ask, Plan, Agent를 언제 사용하는지 알고 있습니다.
- [ ] Copilot의 답이 틀릴 수 있다는 것을 알고 있습니다.
- [ ] 사람이 직접 확인해야 할 일을 두 가지 말할 수 있습니다.
