# GitHub Copilot 기초 사용 가이드

## 개요

GitHub Copilot을 처음 사용하는 사람을 위한 입문 가이드입니다. 개발 경험이 없어도 계정과 프로그램을 준비하는 과정부터 Copilot에게 질문하고 작업을 요청하는 방법까지 단계별로 따라 할 수 있습니다.

준비된 React 시작 프로젝트에서 Copilot에게 계획과 구현을 요청하는 기본 흐름을 익히고, 마지막에는 직접 만들고 싶은 프로젝트를 간단하게 기획합니다.

## 준비물

- 개인 노트북과 인터넷 연결
- GitHub 계정과 GitHub Copilot 사용 권한
- 최신 Visual Studio Code
- GitHub Copilot 확장 프로그램
- Git
- Node.js LTS

실습에서는 [Copilot React Practice](https://github.com/khsystems/copilot-react-practice)를 자신의 GitHub 저장소로 복사해 사용합니다.
